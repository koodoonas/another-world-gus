# Security policy

## Supported version

Security fixes are applied to the latest release only.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting feature for issues that could
affect the host DOS system, corrupt files, or patch an unintended executable.
If private reporting is unavailable, open a minimal issue asking the maintainer
for a private contact channel; do not publish exploit details or proprietary
game material.

Ordinary compatibility failures, freezes, missing audio, and unsupported game
builds should use the bug-report template instead.
